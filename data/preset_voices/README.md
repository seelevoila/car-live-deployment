# 内置汽车主播声音

三套声音随项目保存，启动时自动注册；每个音色固定使用本目录中的主参考、辅助参考、对应文本和采样参数。无需上传克隆音色，也不依赖本机数据库中的其他声音。三套声音共用 GPT-SoVITS v2ProPlus 通用模型。

| 固定名称 | 标识 | 本次采用的现有样本 |
| --- | --- | --- |
| 沉稳阿川 | steady | 桑博 |
| 活力小桃 | energetic | 胡桃 |
| 亲切阿诚 | friendly | 我的主播 |

本次为当前项目演示独立保存已有声音资源，没有训练新说话人，也没有声称这些样本为原创录制或已获得公开分发授权。源记录及音频 SHA-256 保存在 catalog.json。正式参赛对外提交、公开分发或商用时，应核对声音素材授权；如需替换，应成套更新参考录音、逐字文本及测试结果。

catalog.json 使用相对路径，部署时无需修改开发机路径。删除或修改用户克隆记录不会改变这些声音。内置音色不接受克隆编辑、删除、重新绑定或后台自动调参。
