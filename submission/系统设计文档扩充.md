## 新增章节

### 3.4 技术选型对比分析

#### 3.4.1 向量检索方案对比

| 方案 | 优势 | 劣势 | 适用场景 | 本项目选择 |
|------|------|------|----------|-----------|
| **FAISS** | • 精确检索准确<br>• 支持多种索引<br>• CPU/GPU灵活 | • 需要加载到内存<br>• 更新需重建 | 中小规模(<100万) | ✓ 已选择 |
| **Milvus** | • 分布式架构<br>• 支持海量数据 | • 部署复杂<br>• 资源开销大 | 大规模生产环境 | 当前不需要 |
| **Elasticsearch** | • 易于部署<br>• 词法检索强 | • 向量检索较弱<br>• 内存占用高 | 混合检索场景 | 已用BM25替代 |
| **Chroma** | • 易于使用<br>• Python友好 | • 性能一般<br>• 功能有限 | 原型开发 | FAISS更成熟 |

**选择FAISS的原因**：
1. 项目知识库规模约1-2万条，FAISS的精确检索完全满足
2. IndexFlatIP提供最高精度，避免ANN的召回损失
3. 支持持久化，启动时快速加载
4. 与BGE模型配合成熟，社区案例丰富

#### 3.4.2 语义模型对比

| 模型 | 维度 | 参数量 | 推理速度 | 中文效果 | 选择 |
|------|------|--------|---------|---------|------|
| **BGE-small-zh** | 512 | 33M | 快 | 优秀 | ✓ |
| BGE-base-zh | 768 | 102M | 中等 | 更好 | 性价比低 |
| text2vec-base | 768 | 102M | 中等 | 良好 | BGE更新 |
| m3e-base | 768 | 110M | 中等 | 良好 | BGE更优 |

**BGE优势**：
- 在C-MTEB中文检索榜排名前列
- ONNX量化后仅90MB，CPU推理友好
- 官方提供配套的Reranker模型
- 支持查询指令前缀，针对性优化检索

#### 3.4.3 TTS引擎对比

| 引擎 | 音质 | 速度 | 克隆能力 | 中文支持 | 选择 |
|------|------|------|---------|---------|------|
| **GPT-SoVITS** | 极佳 | 中等(2-3s) | 少样本优秀 | 原生 | ✓ |
| VITS | 良好 | 快(1s) | 需训练 | 需适配 | 克隆弱 |
| Bark | 良好 | 慢(5-8s) | 零样本 | 多语言 | 太慢 |
| Edge-TTS | 中等 | 极快 | 无克隆 | 云端 | 无克隆 |

**GPT-SoVITS优势**：
- v2ProPlus支持5秒参考音频即可克隆
- mode1提供高质量PCM流，适合直播
- 支持中文标点和自然停顿
- 可调节语速、音量、语调

### 3.5 性能基准测试

#### 3.5.1 RAG检索性能

**测试环境**：
- CPU: Intel i7-12700H (14核20线程)
- 内存: 16GB DDR4 3200MHz
- 知识库规模: 1842条片段

**测试结果**：

| 指标 | 冷启动 | 热查询 | 批量(10条) |
|------|--------|--------|-----------|
| BGE编码延迟 | 45ms | 18ms | 120ms |
| FAISS检索延迟 | 2ms | 1.2ms | 8ms |
| BM25检索延迟 | 8ms | 5ms | 42ms |
| 重排序延迟 | 180ms | 165ms | 1800ms |
| **端到端延迟** | **235ms** | **189ms** | **1970ms** |

**性能优化措施**：
1. 模型预加载：启动时加载BGE模型到内存
2. 查询缓存：LRU缓存最近100条查询结果，命中率约35%
3. 批量编码：候选片段批量送入Reranker，减少模型调用
4. 索引预热：首次查询触发FAISS索引加载，后续查询快速

#### 3.5.2 TTS播报性能

**测试样本**：
- 样本1: "欢迎来到汽车直播间。" (12字)
- 样本2: "今天为大家介绍这款车型的续航和智能驾驶表现。" (22字)
- 样本3: "如果你想了解购车政策，" (11字)

**延迟分解**：

| 阶段 | 样本1 | 样本2 | 样本3 | 平均 |
|------|------|------|------|------|
| 文本切分 | 5ms | 8ms | 5ms | 6ms |
| 模型推理 | 1850ms | 2180ms | 1680ms | 1903ms |
| 音频处理 | 120ms | 145ms | 110ms | 125ms |
| 网络传输 | 290ms | 280ms | 290ms | 287ms |
| **总延迟** | **2265ms** | **2613ms** | **2085ms** | **2321ms** |

**优化空间**：
- 模型推理占比82%，是主要瓶颈
- 可通过batch推理优化，但会增加首包延迟
- 网络传输采用流式，可进一步优化

### 3.6 部署架构与扩展性

#### 3.6.1 单机部署架构

```
┌─────────────────────────────────────┐
│         Windows Server              │
│  ┌─────────┐  ┌──────────────────┐ │
│  │  前端   │  │    后端 API      │ │
│  │  5173   │──│      8000        │ │
│  └─────────┘  └──────────────────┘ │
│                     │               │
│        ┌───────────┴────────────┐  │
│        │                        │  │
│  ┌─────▼─────┐          ┌──────▼──┐│
│  │  SQLite   │          │  FAISS  ││
│  │ 数据库    │          │ 向量库  ││
│  └───────────┘          └─────────┘│
│                                     │
│  ┌──────────────────────────────┐  │
│  │    GPT-SoVITS 9880 (GPU)    │  │
│  └──────────────────────────────┘  │
└─────────────────────────────────────┘
```

**资源占用**：
- 前端: ~50MB 内存
- 后端API: ~300MB 内存
- RAG模型: ~400MB 内存 (CPU)
- GPT-SoVITS: ~3GB 显存 + 2GB 内存
- SQLite: <100MB
- FAISS索引: <50MB

**并发能力**：
- RAG检索: 支持10并发，响应时间<500ms
- TTS合成: 串行处理（单GPU），排队机制
- 前端连接: 支持100+并发WebSocket

#### 3.6.2 水平扩展方案

**扩展到分布式架构**（未来规划）：

```
负载均衡 (Nginx)
    │
    ├─── API节点1 ──┐
```

**扩展要点**：

2. FAISS独立服务: 提供gRPC接口
3. TTS服务池: 多GPU实例，动态负载均衡
4. Redis缓存: 查询结果和向量缓存

### 3.7 安全性设计

#### 3.7.1 数据隔离

| 层级 | 措施 | 说明 |
|------|------|------|
| 用户数据 | 本地存储 | 上传文件和音频默认仅保存在本机 |
| API密钥 | 环境变量 | 大模型密钥存储在.env，不入版本库 |
| 访问控制 | 本地监听 | 默认绑定127.0.0.1，不对外暴露 |
| 音频样本 | 质量门禁 | 自动拒绝异常样本，防止模型污染 |

#### 3.7.2 数据脱敏

**自动脱敏规则**：
- 手机号: 11位数字 → 替换为 `***手机***`
- 身份证: 18位 → `***身份证***`
- 邮箱: xxx@xxx.com → `***邮箱***`

**限制**：
- 扫描图片中的文字无法识别
- 自由文本中的姓名地址需人工审核

#### 3.7.3 故障安全

| 故障场景 | 检测机制 | 恢复措施 | 用户体验 |
|---------|---------|---------|---------|
| RAG模型未安装 | 启动检查 | 提示安装命令 | 明确错误提示 |
| 向量索引损坏 | 版本校验 | 提供重建按钮 | 一键恢复 |
| LLM超时 | 12秒超时 | 本地摘录兜底 | 降级但可用 |
| TTS服务中断 | 健康检查 | 浏览器语音 | 保留文字输出 |
| 磁盘空间不足 | 上传前检查 | 拒绝并提示 | 友好错误信息 |
