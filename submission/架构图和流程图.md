## 3. 流式TTS播报时序图

```mermaid
sequenceDiagram
    participant U as 前端用户
    participant F as FastAPI
    participant C as 切分引擎
    participant T as GPT-SoVITS
    participant A as AudioContext
    
    U->>F: 提交脚本文本
    F->>C: 按自然停顿切分
    C-->>F: 返回短语列表<br/>[短语1, 短语2, ...]
    
    par 并行处理
        F->>T: 请求合成短语1
        and
        F->>F: 准备短语2请求
    end
    
    T-->>F: 返回短语1 WAV
    F->>F: 剥离WAV头<br/>转PCM数据
    F-->>A: 推送首个PCM
    
    Note over A: T2: ~2300ms<br/>首音频开始播放
    
    A->>A: 排程AudioNode<br/>设置start_time
    
    loop 后续短语
        F->>T: 请求合成短语N
        T-->>F: 返回短语N WAV
        F->>F: 处理PCM
        F-->>A: 持续推送
        A->>A: 连续排程<br/>12ms淡化
    end
    
    Note over A: 播放完成
    A-->>U: 播报结束通知
```

## 4. 动态改稿状态机

```mermaid
stateDiagram-v2
    [*] --> Idle: 无播报任务
    
    Idle --> Loading: 提交脚本
    Loading --> Playing: 首PCM到达
    
    Playing --> Playing: 继续播放<br/>短语N->N+1
    Playing --> Paused: 用户暂停
    Paused --> Playing: 用户继续
    
    Playing --> EditRequested: 用户点击改稿
    EditRequested --> ComputeBoundary: 计算安全边界
    ComputeBoundary --> CancelPending: 取消待生成短语
    CancelPending --> Playing: 切换到新稿<br/>从下一短语开始
    
    Playing --> [*]: 播放完成
    Paused --> [*]: 用户停止
    
    note right of ComputeBoundary
        安全边界 = 当前正在播放的短语索引
        不可变区：index <= safe_boundary
        可变区：index > safe_boundary
    end note
    
    note right of CancelPending
        取消HTTP请求
        清空待排程队列
        使用新脚本重新切分
    end note
```

## 5. 语音克隆质量门禁流程

```mermaid
flowchart TD
    Start([上传参考音频]) --> A[读取音频文件]
    
    A --> B1{格式检查}
    B1 -->|非WAV| B2[转换为WAV]
    B2 --> C
    B1 -->|是WAV| C[提取音频参数]
    
    C --> D{时长检查<br/>5-10秒?}
    D -->|否| Reject1[拒绝: 时长不符]
    D -->|是| E{采样率检查<br/>>=16kHz?}
    
    E -->|否| Reject2[拒绝: 采样率过低]
    E -->|是| F[标准化处理<br/>24kHz单声道16bit]
    
    F --> G[音频质量分析]
    
    G --> H1[计算有效人声比例]
    G --> H2[检测静音段]
    G --> H3[检测削波]
    G --> H4[计算SNR]
    
    H1 --> I{active_ratio<br/>>80%?}
    I -->|否| Reject3[拒绝: 人声不足]
    I -->|是| J
    
    H2 --> J{silence_ratio<br/><20%?}
    J -->|否| Reject4[拒绝: 静音过多]
    J -->|是| K
    
    H3 --> K{clipped_ratio<br/><1%?}
    K -->|否| Reject5[拒绝: 音频失真]
    K -->|是| L
    
    H4 --> L{snr_db<br/>>14?}
    L -->|否| Warning[警告: 噪音较大]
    L -->|是| M
    
    Warning --> M[参考文本检查]
    
    M --> N{文本一致性<br/>chars/duration<br/>合理?}
    N -->|否| Reject6[拒绝: 文本不匹配]
    N -->|是| O[声纹相似度校准]
    
    O --> P{similarity<br/>>85%?}
    P -->|否| Reject7[拒绝: 音色偏差]
    P -->|是| Q[注册音色profile]
    
    Q --> R[模型预热]
    R --> S[标记为ready]
    S --> End([可用于播报])
    
    Reject1 --> Failed([标记为needs_optimization])
    Reject2 --> Failed
    Reject3 --> Failed
    Reject4 --> Failed
    Reject5 --> Failed
    Reject6 --> Failed
    Reject7 --> Failed
    
    style Start fill:#4CAF50
    style End fill:#4CAF50
    style Failed fill:#F44336
    style Warning fill:#FF9800
    style Q fill:#2196F3
```
