# 部署与运行说明

## 运行环境

- Windows 10/11，Python 3.10+，GPT-SoVITS v2ProPlus 本地服务。
- 前端 `5173`，后端 `8000`，本项目 GPT-SoVITS `9881`。`9880` 属于用户另一个应用，不应启动、停止或覆盖。

## 启动

```powershell
cd C:\Users\seele\Desktop\test
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

打开 `http://127.0.0.1:5173`。启动脚本带防重复锁；开机自启动已关闭，不会在登录时自动拉起。

## 验证

```powershell
powershell -ExecutionPolicy Bypass -File .\verify.ps1
```

验证结果写入 `submission/2026-chongqing-ai-competition/evidence/verification.json`。

## 模型与音色

- 默认模型：GPT-SoVITS v2ProPlus。
- 遐蝶使用 `xiandie-fluent` 独立 profile 和 `short-prior-v1.pth`；实验候选不会自动替换注册表。
- 遐蝶及张采用 `checked` 路径：逐句完整生成、验收后传送 PCM；模型内部为 mode 2，不能将首个模型块的耗时当成网页首音频延迟。
- 播报入口等待 `ready` 与 `live_path_warmed` 明确就绪后才开放。未缓存稿件须另行验证首音频时间。
- 参考音频只保存在本机，创建前必须通过文本一致和 PCM 质量检查。

## 故障回退

GPT-SoVITS 不可达时，文字问答仍可用，克隆音色的播报入口保持禁用，不自动替换成浏览器音色。用户选择浏览器语音时才使用 Web Speech。
