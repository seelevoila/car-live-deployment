# 大模型接入接口

未配置时使用本地资料摘录，不连接外部模型。当前可直接在前端“模型接口”页面完成配置。

## 在页面配置（推荐）

1. 打开“模型接口”，填写服务地址、模型名称、API Key及超时秒数。
2. 点击“保存配置”立即生效，或点击“保存并测试连接”同时验证服务连通性。
3. 保存会更新后端 `.env`，下次启动仍然有效。页面保存无需重启，问答和话术生成的后续请求立即使用新配置；已开始的请求继续使用原配置。

已有密钥不会回显。密钥框留空会保留原密钥，输入新值才会替换；无需密钥的本地服务可勾选“此服务无需密钥”。更换服务地址时需要填写新服务密钥或明确清除，避免把原服务密钥发往另一服务。密钥不写入浏览器存储，保存响应、状态接口和错误提示均不返回密钥。

“已保存”和“连接成功”分别表示配置生效与本次连接验证通过。保存失败时保持原文件与运行配置。

## 手动配置文件（可选）

也可以在 `backend/.env` 填写：

```dotenv
LLM_BASE_URL=https://你的模型服务地址/v1
LLM_MODEL=模型名称
LLM_API_KEY=服务密钥
LLM_TIMEOUT_SECONDS=12
```

手动修改文件后需要重启后端。BASE_URL可填写服务根地址、`/v1`地址，或完整的`/chat/completions`地址；不在地址中填写密钥或查询参数。需要服务兼容Chat Completions的`model/messages/temperature`请求及`choices[0].message.content`响应格式。

独立适配文件是 `backend/app/llm_gateway.py`。如果你的服务采用其他协议，只需替换 `generate(question, sources, task)` 和 `probe()`，不用改动知识库、播放或数字主播代码。

| 接口 | 用途 |
| --- | --- |
| GET /api/llm/status | 查看是否配置，不返回密钥；configured不代表已验证服务可达 |
| GET /api/llm/config | 获取地址、模型、超时及是否已保存密钥，不返回密钥本身 |
| PUT /api/llm/config | 保存并即时应用配置；api_key为空或省略则保留，clear_api_key=true则清除 |
| POST /api/llm/test | 用户主动触发连接测试 |
| POST /api/query | 检索→已配置大模型→文字、来源、置信度；失败时回退到本地依据摘录 |
| POST /api/script/generate | 已配置时按卖点和资料生成话术；未配置时按已验证参数生成提纲 |

调用示例：

```json
{
  "question": "这款车的续航和快充时间是多少？",
  "brand": "欧拉",
  "series": "欧拉5 EV",
  "year": "2026",
  "top_k": 5
}
```

资料只在配置模型后随生成请求发往指定地址。数值依据检查可拦截部分无来源数字，但不能证明模型回答完全正确；接入后应重跑自然问句和政策/对比测试。接口故障、超时、空返回和格式错误不会使本地问答变成服务错误。

密钥不要写入前端代码、截图或提交源码包。`backend/.env.example` 只存空配置示例。
