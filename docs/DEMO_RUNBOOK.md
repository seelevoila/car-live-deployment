# 现场演示操作手册

## 启动前检查

1. 运行 `start.ps1`，确认 5173、8000、9881 端口正常。
2. 打开 `http://127.0.0.1:5173`，等待顶部“服务正常”及语音模型、音色预热完成；顶部状态仅代表后端在线。
3. 进入“验证”页运行自测；后端首PCM指标不能代替浏览器完整播放延迟，最新结果见三轮验收报告。
4. 返回“直播台”，选择本轮验证的胡桃音色或对应预置音色。先确认正常播放，再开始正式计时演示。

当前播报链路只使用 GPT-SoVITS v2ProPlus；业务后端为 8000，GPT-SoVITS 服务为 9881。`start.ps1` 是唯一推荐启动入口。

大模型按用户要求暂不接入，界面展示本地资料摘录。接入步骤见 `docs/LLM_INTEGRATION.md`，正式展示赛题“大模型+RAG”链路前需完成接入并复测。

新增功能可依次展示：知识库批量编辑来源/许可→直播台改稿→数字主播的嘴型时差与动作设置→直播统计→音色听测。嘴型时差默认0，嘴早向右调、嘴晚向左调；听测分数由实际听测者填写。

## 动态改稿演示

使用以下三句话，便于观察安全切点：

```text
第一句话，介绍今天的直播主题。第二句话，原本介绍续航表现。第三句话，最后说明购车政策。
```

点击开始播放后，在第一句仍处于播放状态时改为：

```text
第一句话，介绍今天的直播主题。第二句话，改成重点介绍智能驾驶表现。第三句话，最后说明购车政策。
```

点击“应用动态改稿”。预期现象：当前正在播放的短语完整结束，后续句子使用新文案；不会从头重播当前短语。

## 音色演示

参考音频建议 5 到 10 秒（最低 3 秒）、单人普通话、无配乐、无明显混响、录音原文完全一致。上传后观察时长、有效人声比例、静音比例、信噪比、最长静音和 PCM 状态；质量为“建议优化”的音色不可直接播报。系统只裁掉明显首尾空白，保留内部停顿，不会强行降噪、限频或重塑响度。

快速克隆流程：在“上传音频”和“麦克风录制”中二选一。麦克风模式会给出固定朗读文案，点击开始录音，照着文案完整朗读，点击结束录音后先回听；录音会自动转换为 24kHz 单声道 WAV，朗读文案自动作为参考文本。上传模式仍需手动填写与音频逐字一致的参考文本。点击“检查样本”查看 PCM、时长、静音、响度和削波诊断；确认通过后点击“创建我的音色”。创建完成后系统自动预热和校准，状态变为“可立即播报”后可直接“使用”或“试听”。内置主播为“沉稳阿川”“活力小桃”“亲切阿诚”，各自绑定随项目保存的独立声音资源，可在音色卡片中直接试听、使用，不依赖用户上传。音色选择分为内置主播、我的克隆和系统声音；不再提供额外的播报风格组合。克隆管理不能修改、删除或重新绑定内置声音。

## 故障回退

- GPT-SoVITS 不可达：顶部状态保留文字功能，直播台回退 Web Speech API。
- 参考音频缺失或质量不合格：选择预置音色，或使用“优化参考音频”。
- 若首包突然超过 3 秒，检查任务管理器中是否同时运行了两套 GPT-SoVITS 或两套后端；只保留 `start.ps1` 启动的一套服务，避免 GPU 争抢。
- 验证页请求失败：检查后端 8000 端口和 `backend-runtime-error.log`。
