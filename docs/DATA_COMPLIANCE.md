# 数据来源、脱敏与使用范围

本文件描述当前实现及发布前需要核对的资料。未填写的授权不能由系统自动补成“已授权”。

## 来源台账

知识库可批量填写品牌、车系、年款、公开来源地址、资料许可说明和政策有效期。修改生成新版本；问答可展开文档、版本、页码和正文依据。过期资料不参与当前检索，政策冲突保留提示，不自动选取金额更高的一条。

当前演示库中的价格和优惠应由资料提供者补齐来源、时间和适用条件。检索命中仅表明答案来自库内资料，不能证明原资料已经过官方核实。

## 存储与删除

- 新导入 TXT、DOCX 和可提取文本的 PDF，在存储前处理手机号、18 位身份证号和邮箱。DOCX重建正文、表格，去掉原文件批注及附件；PDF执行真实文本遮除并重写，清除元数据。
- 扫描图片、姓名、住址和不规则标识不能靠现有规则可靠识别，上传前仍需人工检查。历史资料和历史备份不会因新规则自动全部重写。
- 文档、版本与片段存于本机 SQLite；上传文件保存在受管目录。删除资料会同时删除关联版本、片段和受管上传文件；外部源文件及用户自行保留的备份不会被删除。
- 运行统计记录时长、问题和来源使用情况。问题日志执行上述标识脱敏。听测表只填写代号，不需要提交姓名、电话等身份信息。

## 音频与数字形象

使用本人或已经取得使用许可的单人语音。原参考录音与规范化副本保存在本机；少样本参考推理不等于训练一个新模型。不得用机器声纹相似度替代真人拟人度评测。

Live2D素材从用户提供的外部目录只读加载。本地演示可用不代表已经取得参赛公开传播或商业使用许可；正式发布前核对模型、角色及参考音频授权，必要时替换素材。当前数字主播实现暂未更新进提交源码ZIP。

## 外部大模型接口

默认未配置外部模型。用户设置服务地址和模型后，问题、卖点及相关资料片段才会随生成请求发往所配置服务；接入前核对该服务的数据处理约定。密钥仅配置在后端环境变量，不进入前端及源码包。

## 本轮证据

自动测试验证三种格式的脱敏存储、Word表格和PDF页码保留，浏览器三轮验证临时资料的批量维护与清理。真人听测记录保持真实空值，未代填分数。详见 `artifacts/implementation-2026-09-07/最终赛题验收报告.md`。
