# 音色拟人度主观评测表

本表用于参赛材料中的主观评测，不用机器指标代替听感评价。建议邀请至少3名听测者，在相同设备、文案和参数下评分；人数及文末4分改进目标是项目建议，不是赛题原文门槛。当前也可在“音色听测”页面选音色、生成试听、保存实际分数并导出JSON。评测时请按实际选择的克隆音色填写。

## 评测条件

- 参考音色：当前选择的克隆音色
- 参考音频：5.21 秒，24kHz，单声道，16-bit PCM
- 试听参数：语速 1.00，表达度 0.60，稳定性 1.35，音量 100%，语调 0
- 试听文案：大家好，欢迎来到汽车直播间。今天我们重点聊聊这款车的续航和智能驾驶表现。
- 快速克隆音色须等待“声纹校准完成”后再试听；校准会筛选同一说话人的辅助参考，并自动选择稳定采样 profile，评测时不要手动覆盖这些参数。
- 评分：1 分很差，3 分一般，5 分优秀
