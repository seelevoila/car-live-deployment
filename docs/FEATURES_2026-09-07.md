# 本轮功能完善

大模型由使用者自行接入；数字主播仅在本地工作区迭代，暂不更新进入提交源码包。

## 知识库

新增资料搜索、全选、批量删除、批量修改品牌/车系/年款/来源地址/授权说明/政策有效期。批量修改生成新版本。来源详情展示文档内容、页码和版本；问答结果展示可展开证据，相关度限制在0–100%且不冒充概率。

导入时保存固定版本的256维归一化哈希向量，查询复用持久化向量；现有资料启动时迁移索引。该实现支持离线运行，尚不属于预训练语义嵌入模型。

新上传TXT、DOCX及可提取文本的PDF会在存储前对手机号、身份证号、邮箱脱敏。DOCX保存为规范化文本/表格，去除原文档批注和附件。扫描图片、自由文本里的姓名地址无法仅靠这些规则可靠识别，仍需资料提供者审核；授权和政策有效期不会由系统虚构。

## 播放与数字主播

修复异步等待推理锁被取消后后台线程取得锁却无法释放的问题；当前模型已就绪时不重复预热。增加参考音频质量缓存，文件修改后自动失效。

前端达到少量PCM预缓冲后开始排程，不再等整个短语下载完成；保留自然语句安全改稿边界。当前语音模型统一为 GPT-SoVITS v2ProPlus mode1。

嘴型使用实际音频输出时钟、20ms语音能量和粗略频带形态，减少二次平滑带来的拖后；嘴型幅度不再随普通音量调小而消失，静音时仍闭嘴。“嘴型同步与动作”可以保存-250至250ms时差和开合幅度，适配不同播放设备。

数字主播加入轻微点头、身体姿态、眼神、眨眼及随说话变化的表情。内置主播固定绑定独立声音，音色选择按“内置主播 / 我的克隆 / 系统声音”分组；语速、音量、语调仍可独立调整。此处是音频驱动的近似口型，不是强制对齐得到的逐音素口型。

## 统计、真实听测与接口

“直播统计”记录实际播放时长、咨询车型、资料检索热点、问题频次、改稿次数与客户端首音频指标。播放上报支持事件ID去重，暂停时间不计入播报时长。

“音色听测”可生成固定文案试听、填写五项真实评分、按音色汇总人数/样本数/平均分，并与运行统计一起导出JSON。没有真实评分时显示空记录，不自动生成拟人度分数。

内置“沉稳阿川”“活力小桃”“亲切阿诚”三套固定汽车主播声音，资源、参考文本和采样参数随项目保存；用户上传音色单独进入“我的克隆”，不会覆盖或重新绑定内置声音。快速克隆支持上传参考音频，或调用麦克风照着固定文案录制；浏览器先回听并转换为 24kHz 单声道 WAV，再复用现有质量检查、预热、校准和试听链路。

“模型接口”提供状态及用户主动连接测试。接入方法见 `docs/LLM_INTEGRATION.md`。

数据迁移前备份位于 `artifacts/implementation-2026-09-07/before-feature-update.sqlite3`。正式的PDF/PPT、云端部署及演示视频需要根据最终接入的模型和真实听测结果更新；本轮不虚报这些交付已经完成。

## 最终复验结果

最后修复后重新完成三轮浏览器验收：每轮40条检索与本地问答均通过；9个模型就绪后的首有声帧估计值为1.68–1.90秒。批量管理、版本/脱敏、暂停继续、增删改稿的实际播放句子、连续取消恢复、三套预置切换和问答播报通过。

57项后端测试、8项嘴型测试及Windows PowerShell统一验证脚本通过。另行导入24短语长稿，连续播放约86秒，无额外音频排程间隙；复用既有参考录音验证了上传、注册、实际合成和删除链路。

完整结果及冷启动、嘴型近似、真人听测和提交材料的边界见 [最终赛题验收报告](../artifacts/implementation-2026-09-07/最终赛题验收报告.md)。资料来源和处理规则见 [数据合规方案](DATA_COMPLIANCE.md)。
